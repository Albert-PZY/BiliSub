### BiliAISub 设计系统 · Midnight Violet

这份文档是 BiliAISub 静态前端和 `#/specs` 页面的视觉约束。实现以 [`app/globals.css`](../../app/globals.css) 为准，业务组件使用语义类名，不引入 Tailwind 或运行时主题库。

### 设计定位

BiliAISub 是一个字幕整理工作台，主要任务是“连接账号 → 解析视频 → 选择分 P → 流式获取 → 在线校对 → 导出”。界面应该帮助使用者快速扫描任务状态和编辑内容，不能使用营销型首屏、装饰性渐变或层层嵌套的卡片。

- **风格**：Minimalism + 工具型命令栏，暗色优先，平面、克制、内容优先。
- **部署**：单一 Next.js 应用，页面与 API 同源，设计上不需要为独立域名或跨域留白。
- **色彩**：深墨蓝为底，电光紫是唯一主操作色，品红只用于强调和提示，语义状态色不参与装饰。
- **密度**：标准偏紧凑，适合反复处理视频和字幕。
- **构图**：顶部常驻命令栏；下方左栏账号、分 P 与任务，右栏编辑与导出；`900px` 以下收为单列。
- **动效**：只保留状态反馈和短过渡，必须遵守 `prefers-reduced-motion`。
- **图形语言**：Lucide 图标、1px 结构线、8px 以内表面圆角、电光紫渐变只出现在品牌标记和进度条。

### Token 架构

Token 分三层：原始值表达颜色和尺寸，语义值表达界面用途，组件规则负责具体控件状态。语义层集中在 `:root` 与 `:root[data-theme="dark"]`。

#### Typography Token

- **字体**：`"Segoe UI"`, `"Microsoft YaHei"`, `"PingFang SC"`, `system-ui`, `sans-serif`。
- **标题字体**：`"Segoe UI Semibold"`, `"Segoe UI"`, `"Microsoft YaHei"`, `system-ui`，用于品牌、命令栏标题、面板标题和规格页标题。
- **等宽字体**：`"Cascadia Code"`, `"SFMono-Regular"`, `Consolas`, `"Liberation Mono"`, `monospace`，用于 BV 号、UID、状态、统计和字幕正文。
- **标题**：命令栏标题 `20px`，规格页标题 `46px`，工作区标题 `13px–14px`。
- **正文**：默认 `14px`，说明文字 `11px–13px`；行高通常为 `1.5–1.75`，字幕正文 `1.95`。
- **字距**：只在品牌副标题和规格页序号使用正字距；标题使用 `-0.01em ~ -0.02em`，正文为 `0`。
- **层级**：先用字号、字重和结构线建立层级，再使用 `--brand` 或 `--accent` 标记状态。

### 页面结构

#### 工作台

1. 顶部 sticky header：品牌、登录状态、规格入口、仓库入口和主题切换；底边有一条紫到品红的渐隐分隔线。
2. **命令栏**：横跨整行的常驻操作区，包含页面标题、限制标记、视频输入、语言选择和“解析并获取字幕”。左侧有一条紫到品红的竖向色条标记它是主操作入口。
3. 左栏 `workbench__rail`：连接账号、分 P 选择、字幕任务；桌面端 sticky 并独立滚动。
4. 右栏 `workbench__stage`：字幕编辑器与导出面板；窄屏时自动落到命令栏与左栏之后。
5. 未连接账号时使用 `workbench--solo`：隐藏左栏，命令栏提示先登录，编辑器显示对应空状态。
6. 移动端：`900px` 以下单列；`560px` 以下收紧顶栏、状态 chip 只保留圆点（完整文本保留在可访问名称和 `title` 中），命令栏隐藏限制标记并让输入区纵向堆叠。

#### 规格页

规格页是当前实现的事实索引，不是测试运行器，也不复制参考站的测试模块。内容分为处理边界、状态顺序和部署边界三段；每段使用平面结构线和有限卡片表达，`768px` 以下变成单列。

### 组件规则

#### Button

- 默认高度 `44px`，大按钮 `48px`，小按钮 `40px`。
- 主操作使用 `--brand` 与 `--glow-brand` 发光阴影；次操作使用 `--surface-subtle` 和 `--line`；危险操作使用 `--danger`。
- 图标放在文字左侧，使用 Lucide；仅图标按钮必须提供 `aria-label` 和 `title`。
- hover 只改变颜色、边界和阴影，不使用会改变布局的缩放和位移。
- disabled 状态降低透明度并禁止点击，不能只依赖颜色表达。

#### Input

- `textarea`、`select`、搜索输入和文本输入使用 `--surface-subtle`、`--line`、`--radius-sm`，聚焦时背景抬升到 `--bg-elevated`。
- focus 使用 `--shadow-focus`、`--brand` 边界和 `2px` 可见轮廓，不能删除可见焦点。
- 错误信息紧邻控件，使用 `role="alert"`；提示文本说明实际原因和下一步。
- 命令栏中的视频输入在桌面端压缩为单行高度，`560px` 以下恢复为可换行的多行输入。

#### Task row

- 每个任务行最小高度 `58px`，左侧有一条 2px 状态条，选中时切换为紫到品红渐变。
- 成功、加载、失败和解析失败使用不同图标和语义色。
- 可选择项使用原生 `button`，通过 `aria-pressed` 暴露选择状态；不可选择的失败项保持可见但禁用。
- 列表超过实际限制时保持滚动容器，不在当前上限内引入虚拟化依赖。

#### Editor

- 字幕正文使用等宽字体和 `1.95` 行高，便于逐行校对。
- 语言切换使用 `role="tablist"`、`role="tab"` 和键盘方向键；当前语言使用实心 `--brand` 反白标记。
- 修改状态显示在语言标签和统计信息中；恢复原文前不需要弹窗。
- SRT 导出尽量保留原始时间轴；纯文本编辑无法推断新时间轴时，使用明确的回退规则。

### 状态与动效

- 加载状态保留原有布局，用 `Loader2` 和 `aria-live` 告知进度；流式字幕到达后立即更新列表。
- Toast 使用左侧语义色条、短时、可关闭、非阻塞提示；定时器在 Provider 卸载时清理。
- 普通过渡使用 `160ms`，进度条与选择使用 `220ms`；不为装饰添加持续动画。
- `@media (prefers-reduced-motion: reduce)` 下关闭滚动、旋转和过渡动画。

### 不使用的模式

- 不使用绿色系（青绿、薄荷、草绿）或紫蓝渐变背景、光晕、bokeh、装饰性网格贴图。
- 不使用营销型 hero、重复的统计数字或与字幕流程无关的功能卡片。
- 不使用 emoji 代替图标，不使用纯颜色表达错误，不使用不可访问的可点击 `div`。
- 不在普通表面使用超过 `8px` 的圆角，不把卡片嵌套在卡片中。
- 不使用固定高度包裹会增长的字幕正文，不让按钮文字溢出或在 hover 时改变尺寸。
